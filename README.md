# Dhruv Patel | Developer Portfolio 🚀

A modern, responsive, dark-mode developer portfolio showcasing web interfaces, frontend skills, and featured projects. Built with vanilla HTML, CSS, JavaScript, GSAP animations, Lenis smooth scroll, and HTML5 Canvas.

🌐 **Live Demo:** [https://my-portfolio-fd.vercel.app/](https://my-portfolio-fd.vercel.app/)

---

## ✨ Features

- **Interactive Canvas Background:** Dynamic plexus particle animation rendered on HTML5 Canvas.
- **Custom Cursor & Spotlight Glow:** Interactive cursor ring and cursor-following ambient spotlight effect (desktop).
- **Smooth Animations & Scroll Triggers:** Powered by **GSAP** & **ScrollTrigger** for staggered entry reveals.
- **Lenis Smooth Scroll:** Fluid, inertia-driven page scrolling experience.
- **Modern Glassmorphism UI:** Dark theme aesthetic featuring backdrop blurs, glow accents, and responsive layout.
- **Mobile Responsive Drawer & Carousel:** Touch-friendly mobile navigation drawer and horizontal snap carousel for projects.
- **Working Contact Form:** Integrated contact form with validation and status indicators.

---

## 🛠️ Tech Stack

- **Core:** HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Animations:** GSAP (GreenSock), ScrollTrigger
- **Scrolling:** Lenis Smooth Scroll
- **Icons & Fonts:** Lucide Icons, Remix Icon, Google Fonts (*Space Grotesk*, *Plus Jakarta Sans*)
- **Deployment:** Vercel

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhruvpatel012/my-portfolio.git
   cd my-portfolio
   ```

2. **Open in Browser:**
   Simply open `index.html` in your favorite web browser or run it using a local server extension like **Live Server** in VS Code.
